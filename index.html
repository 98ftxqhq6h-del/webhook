Webhook helper

Connect GitHub to IFTTT

Build the IFTTT Webhooks URL for a GitHub repository webhook, then copy the settings into GitHub.

Step 1

Create your IFTTT trigger URL

Open IFTTT Webhooks

Step 2

Add it in GitHub

  1. Open your repository on GitHub, then go to Settings and Webhooks.
  2. Choose Add webhook and paste the generated URL into Payload URL.
  3. Set Content type to application/json.
  4. Select the events you want, usually Just the push event for a first test.
  5. Keep Active checked, then click Add webhook.
GitHub sends a ping event after saving. In IFTTT, create an Applet with Webhooks as the trigger and use the same event name.
